# Forum Pan — 轻量级论坛 + 即时通讯系统（C/S 架构）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

基于 PHP + MySQL 的轻量级一体化 Web 应用，采用 **C/S 架构**：总端集中管理数据库，客户端节点通过 TCP 协议通信。支持论坛发帖、私聊、群聊、网盘存储，适配**无 Cookie 设备**。

---

## 架构

```
┌──────────────────────────────────────────────────┐
│                    总端（外网 / 内网）             │
│  ┌──────────────┐     ┌──────────────────┐       │
│  │ db_server.php │────▶│  MySQL (forum_pan)│       │
│  │  TCP :9527    │     └──────────────────┘       │
│  └──────────────┘                                 │
└────────┬──────────────┬──────────────┐            │
         │ TCP          │ TCP          │ TCP        │
         ▼              ▼              ▼            │
┌─────────────┐ ┌─────────────┐ ┌─────────────┐     │
│ 客户端节点 1 │ │ 客户端节点 2 │ │ 客户端节点 N │     │
│ PHP Web 服务 │ │ PHP Web 服务 │ │ PHP Web 服务 │     │
│ :8080        │ │ :8080        │ │ :8080        │     │
└─────────────┘ └─────────────┘ └─────────────┘     │
      ▲               ▲               ▲             │
      │ HTTP          │ HTTP          │ HTTP        │
      ▼               ▼               ▼             │
 ┌────────┐     ┌────────┐     ┌────────┐           │
 │ 设备 1  │     │ 设备 2  │     │ 设备 N  │           │
 │ (内网)  │     │ (内网)  │     │ (内网)  │           │
 └────────┘     └────────┘     └────────┘           │
```

- **总端**：一台服务器，运行 `db_server.php`，集中管理 MySQL
- **客户端节点**：多台内网服务器，运行 PHP Web 应用，通过 TCP 连接总端
- **终端设备**：通过 HTTP 访问客户端节点，**无需外网访问能力**

## 功能

### 论坛模块
- **发布帖子** — 支持标题 + 内容，带附件上传
- **帖子列表** — 按置顶/时间排序，支持分页和每页条数选择
- **实时评论** — 3 秒自动刷新新评论，支持附件
- **点赞功能** — 帖子和评论均可点赞/取消，防重复
- **撤回功能** — 3 分钟内可撤回自己的内容，管理员无限制

### 即时通讯
- **私聊** — 与任意用户一对一聊天，未读红点提醒
- **群聊** — 创建多人群组，实时消息推送
- **消息撤回** — 3 分钟内可撤回，管理员无限制

### 网盘存储
- **文件上传** — 单文件最大 50MB，默认配额 1GB
- **文件预览** — 图片点击大图预览（暗色背景）
- **文件下载** — 支持所有文件类型
- **存储管理** — 实时显示已用/总配额，删除自动释放

### 用户管理
- **验证码注册** — 管理员生成 8 位验证码，用户凭码注册
- **限时开放注册** — 管理员可开启 5 分钟自由注册（无需验证码）
- **昵称系统** — 用户可设置昵称，优先显示昵称
- **修改密码** — 个人中心支持修改密码（bcrypt 加密）
- **多配色主题** — 支持琥珀金、粉钻、纯净白、纯黑、科技蓝 5 种配色

### 管理员功能
- 生成注册验证码
- 管理用户（禁用/删除）
- 管理帖子（置顶/精华/删除）
- 管理评论（删除）
- 敏感词管理（替换或拦截）
- 限时开放注册控制

### 无 Cookie 适配
- Session ID 通过 URL 参数传递
- 主题和分页设置使用 Cookie → Session 双存储
- 适配不支持 Cookie 的嵌入式设备浏览器

## 技术栈

- **后端**: PHP 5.6+（推荐 7.3+）
- **数据库**: MySQL 5.7+（utf8mb4 字符集）
- **协议**: JSON 行协议（TCP 通信）
- **前端**: 原生 HTML / CSS / JavaScript
- **实时通讯**: AJAX 轮询
- **密码加密**: bcrypt（`password_hash` / `password_verify`），兼容旧版 MD5 自动升级

## 快速部署

### 环境要求

- PHP 7.3+（推荐 phpstudy 集成环境）
- MySQL 5.7+
- 总端需开放 TCP 端口 9527

### 步骤一：部署总端

1. 将 `server/` 目录上传到外网服务器
2. 编辑 `server/启动总端.bat`，修改数据库配置：
   ```batch
   set DB_HOST=localhost
   set DB_USER=root
   set DB_PWD=your_password
   set DB_NAME=forum_pan
   ```
3. 初始化数据库：
   ```bash
   mysql -u root -p < server/init.sql
   ```
4. 放行防火墙端口：
   ```bash
   # Windows 防火墙
   netsh advfirewall firewall add rule name="Forum Pan" dir=in protocol=tcp localport=9527 action=allow
   ```
5. 双击 `server/启动总端.bat` 启动服务

### 步骤二：部署客户端节点

#### 方式一：phpstudy（推荐）

1. 将项目根目录复制到内网服务器
2. 打开 phpstudy → 网站 → 创建网站
   - 域名：`localhost`
   - 端口：`8080`
   - 根目录：选择项目根目录
   - PHP 版本：7.3+
3. 编辑 `config.php`，修改总端 IP：
   ```php
   define('TCP_HOST', '123.45.67.89');  // 改为总端公网 IP
   ```
4. 启动网站，浏览器访问 `http://localhost:8080`

#### 方式二：PHP 内置服务器

双击 `启动客户端节点.bat`（自动检测 phpstudy 或系统 PHP）

### 步骤三：访问系统

浏览器打开：`http://客户端节点IP:8080`

### 默认管理员账号

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin123 | 管理员 |

> **首次登录后密码自动升级为 bcrypt 加密，建议立即修改密码。**

## 使用流程

1. **管理员登录** → 进入后台 → 生成注册验证码
2. **新用户** → 使用验证码注册账号 → 登录系统
3. **论坛** → 浏览帖子 / 发布新帖 / 评论 / 点赞
4. **私聊** → 选择用户 → 实时聊天
5. **群聊** → 创建群组 → 邀请成员 → 多人聊天
6. **网盘** → 上传 / 下载 / 管理文件
7. **个人中心** → 修改昵称 / 修改密码 / 退出登录

## 多节点部署

```
外网服务器                      内网区域 A                内网区域 B
┌──────────┐                 ┌──────────────┐         ┌──────────────┐
│  总端     │◀────TCP───────▶│ 客户端节点 1  │         │ 客户端节点 2  │
│ :9527    │                 │ :8080        │         │ :8080        │
│ + MySQL  │                 │              │         │              │
└──────────┘                 └──────┬───────┘         └──────┬───────┘
                                    │ HTTP                    │ HTTP
                              ┌─────┴─────┐            ┌─────┴─────┐
                              │ 设备 A-1  │            │ 设备 B-1  │
                              │ 设备 A-2  │            │ 设备 B-2  │
                              └───────────┘            └───────────┘
```

- 各客户端节点独立部署，可自定义端口
- 所有客户端共享总端数据库，数据实时同步
- 终端设备仅需内网访问，不依赖外网

## 安全特性

| 特性 | 说明 |
|------|------|
| SQL 注入防护 | 所有用户输入统一使用 `tcp_real_escape_string()` 转义 |
| XSS 防护 | 消息渲染使用 `escapeHtml()` 转义 + `htmlspecialchars()` |
| 密码加密 | bcrypt 哈希（`password_hash`），兼容旧 MD5 自动升级 |
| 参数白名单 | `type` 等关键参数使用 `in_array` 白名单验证 |
| 连接降级防护 | TCP 连接失败时返回错误，不使用不安全的 `addslashes` |
| 权限控制 | 管理员/普通用户角色分离，API 层双重鉴权 |
